What This Does Detects real-world horizontal planes using WebXR hit-test Shows a reticle when a surface is found On tap/click → anchors a 3D box to that plane Important Notes Requires HTTPS. Works on Android Chrome with WebXR enabled. iOS Safari does not support WebXR plane detection yet. If you're using marker-based AR.js instead, anchoring works differently (attached to marker entity).
